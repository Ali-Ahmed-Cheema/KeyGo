# Frontend Architecture

## Implemented

- App bootstrap and view-model shell in `KeyGo.App`
- Basic provider management and project initialization services
- Chat model and project service integration at the application layer

## Experimental

- WinUI view composition and app-host wiring for provider and chat flows
- MVVM patterns around project, provider, and agent navigation

## Planned

- Full conversation list, message list, composer, provider selector, model selector, and context inspector UI
- Streaming response rendering, markdown/code blocks, copy actions, retry, and stop controls
- Activity timeline, settings, command palette, and provider connection center
