# Project Context

## Implemented

- Project directory discovery, indexing, and file classification
- Search and line-aware project references
- Context budgeting and relevance ranking
- Secret scanning and conservative exclusion of likely secret-bearing files
- Local-only privacy enforcement

## Experimental

- Context preview and partially ranked file inclusion for multi-file tasks
- Smarter selection heuristics for source/test/documentation files

## Planned

- Full context inspector UI with token totals, excluded secret count, privacy mode display, and file review
- Incremental re-indexing, symbol-aware code context, and dependency-aware selection
- More resilient secret detectors and user-review workflows
