KEYGO — LARGE IMPLEMENTATION SPRINT
Project Workspace + Repository Intelligence + Context Engine + Read-Only Coding Agent
Mission
KeyGo currently has an early-stage .NET foundation for:

Local-first AI
Provider abstraction
Provider routing
Secure credential handling
Usage/cost tracking
Permissions
Desktop application
Testing
Architecture/security documentation

The next objective is to transform KeyGo from a provider/API workspace into a real developer workspace.
Build a large, integrated vertical slice covering:
Open Project
      ↓
Understand Project
      ↓
Index Repository
      ↓
Analyze Structure
      ↓
Search Code
      ↓
Build Context
      ↓
Ask AI About Project
      ↓
AI Explains Project

The AI must initially operate in READ-ONLY mode.
Do NOT implement unrestricted autonomous editing yet.

2. PROJECT WORKSPACE
Implement the concept of a KeyGo Project.
A project represents a local folder/repository.
Example:
KeyGo
│
├── Projects
│
│   └── MyReactApp
│       ├── Path
│       ├── Git information

Remove Project

Do not copy the entire project into KeyGo.
