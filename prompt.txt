KEYGO — LARGE-SCALE VERTICAL SLICE IMPLEMENTATION
Objective
The KeyGo codebase is currently a structured .NET 10 / C# foundation with WinUI 3, KeyGo.Core, KeyGo.App, tests, provider abstractions, secure credential architecture, project services, permissions, usage tracking, and supporting documentation.
Stop treating the next milestone as another isolated backend module.
Build the first complete end-to-end KeyGo AI workspace vertical slice.
The goal is to transform KeyGo from a technical foundation into a genuinely usable Alpha desktop application.
Do not rewrite the architecture unnecessarily. Inspect the existing code first, preserve good abstractions, and integrate with what already exists.

FINAL GOAL
At the end of this implementation, KeyGo should no longer be accurately described as:

"A .NET foundation for a future AI application."

It should be demonstrable as:

"A working local-first Windows AI development workspace where developers can securely connect their own AI provider, discover models, chat with them, provide project context, monitor usage, and perform permission-controlled coding actions."

That is the first genuinely meaningful KeyGo product milestone.
Build this as an integrated production-quality Alpha, not as a collection of disconnected demos.
